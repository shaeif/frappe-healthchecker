# AMC Tracker

Frappe v16 app for tracking Annual Maintenance Contracts (AMCs): clients, their AMCs, the engineers
assigned to each AMC by area of expertise, periodic preventive maintenance (PM) visits, PM reports and
sign-off, with UI-editable notification rules (email, Microsoft Teams and in-app pop-ups).

See the repository root `README.md` for installation, Docker, configuration and test instructions.
