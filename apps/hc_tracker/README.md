# HC Tracker

Frappe v16 app for tracking periodic network health checks (Cisco switches and WLCs,
Palo Alto and FortiGate firewalls) with a fully configurable, UI-editable notification flow
(email, Microsoft Teams Workflows webhooks, and in-app pop-up/bell notifications).

See the repository root `README.md` for installation, Docker, configuration and test instructions.
